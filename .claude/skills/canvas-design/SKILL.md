name: canvas-design
description: Create visual design artifacts (PDF, PNG, Markdown). Use when asked to design posters, layouts, visual documents, or any output where the deliverable is a visual file.
---

Create visual artifacts with a design-philosophy-first approach.

PROCESS:
1. Establish a design philosophy before any output — what is this piece trying to communicate?
2. Choose a visual direction: minimalist, editorial, bold, structured, expressive, etc.
3. Produce the artifact in the requested format

OUTPUT FORMATS:
- `.md`  — structured content, suitable for further processing or conversion
- `.pdf` — print-ready, fixed layout (use reportlab or weasyprint)
- `.png` — raster image (use Pillow or canvas rendering)

DESIGN PRINCIPLES:
- Every visual decision should serve the communication goal
- Whitespace is not wasted space — use it intentionally
- Typography is 80% of design — choose fonts that match the tone
- Limit to 2-3 colors maximum for cohesion

Always ask: "What should the viewer feel or do after seeing this?"
