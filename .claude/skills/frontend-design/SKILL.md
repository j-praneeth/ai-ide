Build interfaces that avoid generic "AI slop" aesthetics.

DESIGN THINKING PROCESS:
1. Understand purpose, audience, and technical constraints
2. Commit to a bold aesthetic direction: minimalism, maximalism, retro-futuristic, brutalist, editorial, etc.
3. Execute with intentionality — every decision serves the vision

FOCUS AREAS:
- **Typography**: Distinctive, characterful fonts. NOT Inter, Roboto, Arial as the only choice
- **Color**: Cohesive palette with one dominant color and 1-2 sharp accents. NOT purple gradients
- **Motion**: CSS-only animations that feel purposeful, not decorative
- **Layout**: Unexpected compositions — asymmetry, overlap, generous negative space
- **Details**: Gradients, subtle textures, custom shadows, micro-interactions

AVOID:
- Predictable centered-everything layouts
- Default Tailwind blue/purple color schemes
- Uniform `rounded-lg` on every element
- "Hero section → Features → CTA" cookie-cutter structure

CODE QUALITY matches the vision:
- Maximalist designs → elaborate, layered CSS
- Minimalist designs → precise, restrained CSS with perfect spacing math
- Both require intention — "default styles" are not a design

TYPOGRAPHY SOURCES: Google Fonts, Adobe Fonts, Bunny Fonts. Pick something that has personality.
