Three-stage collaborative document creation workflow.

STAGE 1 — CONTEXT GATHERING:
- Ask 5–10 clarifying questions: document type, audience, desired impact, format, constraints, tone
- Accept stream-of-consciousness input or linked sources
- Track unknowns explicitly — surface them throughout

STAGE 2 — REFINEMENT & STRUCTURE:
- Work section by section:
  1. Clarify the section's purpose
  2. Brainstorm 5–20 structural options
  3. User curates direction
  4. Check for gaps
  5. Draft
  6. Iterate with surgical string-replacement edits
- Trigger quality check after 3 iterations without substantial change
- Full document review near completion: flow, consistency, redundancy, filler words

STAGE 3 — READER TESTING:
- Simulate a reader with no prior context answering the document's key questions
- Success = reader consistently gets correct answers without ambiguity
- Without sub-agents: provide a separate-conversation test prompt for the user to run

EDITING PRINCIPLE: Prefer targeted replacements over full rewrites. Preserve voice and structure unless explicitly asked to change them.
